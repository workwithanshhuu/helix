# Code of conduct

Helix follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code and ideas rather than people, and keep discussions technical. Unacceptable behaviour can be reported privately to the maintainer through GitHub. Maintainers may remove comments, commits or contributions that violate these principles.
