# tools/bpf — bpftrace scripts (day 41)

`runqlat`-style run-queue latency for helixd threads, off-CPU stacks, TCP retransmits on Helix ports. Used to explain tail latency ([docs/concepts/observability-and-tail-latency.md](../../docs/concepts/observability-and-tail-latency.md)). Requires root and kernel headers.
